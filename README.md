# 🌐 Shelby AI Gateway

The intelligent entry point for global AI inference. This gateway routes user requests to the optimal **Shelby Global Storage** nodes using real-time Geo-IP intelligence.

## 🚀 The Vision
In a decentralized world, latency is the enemy of AI. This project solves that by leveraging **DoubleZero's fiber backbone** to ensure AI Agents fetch their brains (models) from the closest possible node.

## ✨ Key Features
- **Geo-Aware Routing:** Automatically detects user location to minimize hop counts.
- **Failover Protection:** If one node is congested, the gateway re-routes via the next fastest path on Shelby.
- **Enterprise Ready:** Perfect for dApps that require sub-second model loading.

## 🛠 Setup
1. `npm install`
2. Set `SHELBY_API_KEY` in `.env`.
3. `node gateway.js`
